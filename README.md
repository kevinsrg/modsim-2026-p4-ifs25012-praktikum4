# Simulasi Memasak & Tangki Air

Aplikasi simulasi berbasis fisika menggunakan Streamlit.

## 🚀 Cara Menjalankan Lokal

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📦 Daftar Aplikasi

- `app.py` — Simulasi proses memasak nasi
- `appstd.py` — Simulasi tangki air

## 🌐 Deploy

Deployed via [Streamlit Community Cloud](https://share.streamlit.io)
